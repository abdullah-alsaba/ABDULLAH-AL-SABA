Description

SportNest is a full-stack sports facility booking management system. Users can browse and search for sports facilities, filter by type, view detailed facility information, and book available slots by selecting a date, time slot, and duration. The platform also allows users to view and cancel their own bookings.

Key Features

  • Browse, search, and filter sports facilities by type
  • Book facilities by selecting date, time slot, and duration
  • View and cancel personal bookings
  • Add, update, and delete facility listings
  • Secure authentication — email/password and Google OAuth via Better Auth
  • JWT verification on the backend to protect sensitive API routes
  • Separate client and server architecture connected through REST APIs
  • Deployed on Vercel with MongoDB Atlas as the database

Challenges Faced

Implementing JWT-based route protection across a decoupled client-server architecture required careful coordination of token handling on both ends. Syncing authentication state (Better Auth + Google OAuth) with backend-verified JWTs, while maintaining a smooth UX, was the most complex part of the build.

Future Improvements

Add real-time availability updates with WebSockets, implement an admin dashboard for facility owners, introduce payment gateway integration, and add email confirmation notifications for bookings.
