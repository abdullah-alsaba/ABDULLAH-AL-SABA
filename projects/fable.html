Description

Fable is a full-stack digital ebook sharing and publishing platform designed for readers and independent writers. Readers can discover, purchase, bookmark, and read ebooks, while writers can publish and manage their own books.

The platform includes role-based access for Readers, Writers, and Admins, secure authentication with BetterAuth and JWT, Stripe payments, imgBB image uploads, search and filtering, pagination, responsive dashboards, and admin analytics with interactive charts.

Key Features

  • Role-based dashboards and access control for Readers, Writers, and Admins
  • Secure authentication with email/password login, Google OAuth, BetterAuth, and JWT
  • Readers can browse, search, filter, bookmark, purchase, and read ebooks
  • Writers can publish, edit, unpublish, and manage their ebooks and sales
  • Stripe Checkout integration for ebook purchases and writer publishing payments
  • Admin dashboard with user management, ebook moderation, transaction history, and analytics charts
  • Responsive UI with dark mode, loading states, skeleton loaders, and smooth Framer Motion animations
  • imgBB integration for ebook cover and profile image uploads

Challenges Faced

One of the main challenges was managing different user roles and permissions across the platform. Each role required different dashboard features and access levels, so I had to carefully handle authentication, authorization, and protected routes.

Integrating Stripe was another important part of the project. I needed to connect the payment flow with the backend so that successful purchases were properly recorded and the purchased ebook could be unlocked for the reader. Keeping the frontend, backend, authentication, and database state synchronized required careful API and data-flow planning.

Future Improvements

Future improvements could include a more advanced recommendation system, reader reviews and ratings, personalized reading lists, improved writer analytics, email notifications, and additional payment and publishing features.
